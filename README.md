# TripMate — проектирование базы данных

Курсовой проект по дисциплине «Базы данных», ИТМО, факультет технологического менеджмента и инноваций.

## О проекте

TripMate — концепция платформы для поиска попутчиков и организации совместных путешествий, где пользователи могут создавать собственные туры, находить компаньонов по интересам и бронировать поездки. Проект включает проектирование реляционной схемы БД, валидацию данных, аналитические представления, хранимые функции, триггеры для поддержания целостности данных и запросы с оконными функциями.

## Структура

- **`schema.sql`** — схема БД: 9 сущностей (users, trips, trip_requests, saved_trips, reviews, userpreferences, messages, waypoints, trip_waypoints), первичные и внешние ключи, CHECK-ограничения с регулярными выражениями для валидации email, телефона, пола, имени и текста отзывов.
- **`views.sql`** — 7 представлений: профиль пользователя с рейтингом, отзывы по турам, популярные туры по числу сохранений, предстоящие поездки пользователя, участники тура, предпочтения пользователей, точки маршрута на карте.
- **`functions.sql`** — 8 хранимых функций на PL/pgSQL (скалярные и табличные): расчёт среднего рейтинга, подбор туров по предпочтениям пользователя (основа рекомендательной логики), список участников тура, количество активных туров автора и др.
- **`triggers.sql`** — 8 триггеров для автоматизации и целостности данных: автоустановка даты регистрации, пересчёт рейтинга при новом отзыве, проверка возраста (16+), запрет дублирующих отзывов, каскадное удаление зависимых записей и др.
- **`window_functions.sql`** — 5 аналитических запросов с оконными функциями (`COUNT() OVER`, `RANK()`, `ROW_NUMBER()`, `SUM() OVER`, скользящее среднее с `ROWS BETWEEN`).

## Стек

PostgreSQL, PL/pgSQL.
